# attention_ds003969_crown8

Crown8 re-parse of OpenNeuro `ds003969` attention windows.

- **montage_id:** `crown8`
- **channels (stream order):** CP3, C3, F5, PO3, PO4, F6, C4, CP4
- **sample_rate_hz:** 256.0
- **labels:** same as muse4 pack (`concentration` / `mind_wandering`)
- **window alignment:** identical `starts` / `y` as `datasets/attention_ds003969/windows/`
- **license:** CC0-1.0 (OpenNeuro)
- **recordings:** 64

Never mix with muse4 examples. Sleep-EDF is not used for Crown.
